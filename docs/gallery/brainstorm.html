Brainstorm

Compile presentation instead of authoring it

Accepted direction for artifact delivery, with the alternatives that were weighed.

Note

Outcome contract

A skill emits a declarative Page Spec and the compiler owns HTML, CSS, JavaScript, accessibility, and the security policy.

Compared approaches

Hand-authored HTML per skill

  • Full control over every artifact.
  • Each skill carries its own CSS, JavaScript, and accessibility debt.
  • Presentation drifts between skills over time.

Typed compiler with a Page Spec

  • One implementation of presentation for every skill.
  • Deterministic output, so the same spec yields identical bytes.
  • Offline by default, with no CDN or font fetch.
