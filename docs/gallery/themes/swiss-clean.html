Note

Themes are typed data

A preset sets declared tokens only; it cannot introduce a declaration.

How a preset resolves

  1. Load

    Built-in presets, then user, project, and explicit files.

  2. Extend

    Each preset merges over the chain it extends.

  3. Complete

    A token left unset falls back to the default preset and warns.

Preset versus stylesheet

Preset

  • Declared tokens only
  • Validated values

Stylesheet

  • Arbitrary declarations
  • Unvalidated input
  • Unpredictable output
